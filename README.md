# Mini App (Telegram)

Веб-приложение, которое открывается внутри Telegram через кнопку-меню или
инлайн-кнопку у бота. Пока это интерфейс-макет (демо), без подключения к backend.

## Файлы

- `index.html` — каркас (шапка, контейнер страниц, нижняя навигация)
- `styles.css` — тёмная тема с сине-фиолетовым акцентом
- `app.js` — SPA-логика: 5 страниц (Главная, Тарифы, Устройства, Профиль, Помощь)

## Быстро посмотреть в браузере

Просто открой `index.html` двойным кликом — приложение отрендерится и без Telegram
(профиль просто покажет «Гость»).

## Проверить как Mini App в Telegram

1. Эти файлы нужно разместить по **HTTPS**-адресу (любой статический хостинг:
   GitHub Pages, Vercel, Netlify, Cloudflare Pages, или твой будущий сервер).
2. В @BotFather: команда `/newapp` → выбери своего бота → укажи название и
   короткое имя → пришли ссылку на `index.html`.
3. BotFather даст ссылку вида `t.me/your_bot/app` — открой её в Telegram.

## Подключение к боту (следующий шаг)

Чтобы тарифы/устройства/профиль брались из базы бота, нужен небольшой HTTP-API:
мини-приложение шлёт `tg.initData` на backend, тот проверяет подпись и отвечает
данными пользователя. Сделаем это после того, как бот переедет на сервер.
